# SAP ABAP Developer

Toolkit de skills para desarrollo SAP ABAP en Claude Code.

- **Desarrollo:** abap-code-writing, clean-abap, code-reviews-abap, abap-performance-ecc, abap-performance-hana
- **Investigación:** abap-research, adt-api-discovery, sap-customizing, sap-background-jobs, sap-system-personality-report, sap-data-workbook, repository-assisted-apply
- **Testing UI (Playwright/WebGUI):** sap-testing, analyze-and-plan, explore-ui, design-cases, define-data, prepare-data, build-scripts, run-scripts, helpers-reference, sap-webgui, sap-webgui-recording, multi-system-workflows, anst-guide

Instalación:
```
/plugin marketplace add <ruta-a-esta-carpeta>
/plugin install sap-abap-developer@juan-sap-tools
```
Las skills quedan como `sap-abap-developer:<skill>`.
